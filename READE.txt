============================================================
DESCRIPCIÓN DEL PROYECTO
============================================================

Beauty Store es una tienda online ficticia dedicada a la venta
de productos de belleza, maquillaje y cuidado personal.

El sitio web fue desarrollado como proyecto académico utilizando
HTML5, CSS/Sass, Bootstrap 5, JavaScript y Vite.

El proyecto cuenta con diferentes páginas interconectadas,
diseño responsivo, navegación entre secciones, catálogo de
productos, ofertas, favoritos, carrito de compras dinámico,
formulario de contacto y un proceso de checkout simulado.


============================================================
OBJETIVO
============================================================

El objetivo de este proyecto es aplicar los conocimientos
adquiridos durante el curso de desarrollo web mediante la
creación de un sitio web funcional, organizado, responsivo
e interactivo.

Se utilizaron elementos semánticos de HTML5, estilos
personalizados, componentes de Bootstrap y funcionalidades
desarrolladas con JavaScript.


============================================================
TECNOLOGÍAS UTILIZADAS
============================================================

- HTML5
  Utilizado para crear la estructura y organización semántica
  de las páginas.

- CSS y Sass
  Utilizados para personalizar colores, fondos, tipografías,

  Utilizados para el control de versiones y almacenamiento

  Utilizado para publicar el sitio web en Internet.


============================================================
ESTRUCTURA DEL SITIO
============================================================

El proyecto contiene las siguientes páginas:

1. index.html
   Página principal de Beauty Store.

2. productos.html
   Catálogo general de productos.

3. categorias.html
   Presenta las diferentes categorías de productos.

4. ofertas.html
   Presenta productos disponibles a precios especiales.

5. novedades.html
   Presenta productos nuevos o destacados.

6. favoritos.html
   Presenta una selección de productos favoritos.

7. carrito.html
   Carrito de compras dinámico.

8. pago.html
   Página de checkout y proceso de pago simulado.

9. nosotros.html
   Información sobre Beauty Store, su historia, misión,
   visión y valores.

10. contacto.html
    Formulario de contacto con validación.

11. preguntas.html
    Sección de preguntas frecuentes.

12. politicas.html
    Información sobre compras, envíos, devoluciones,
    privacidad y términos generales.

============================================================
CARRITO DE COMPRAS
============================================================

El carrito de compras fue desarrollado utilizando JavaScript
y LocalStorage.

Cuando el usuario selecciona "Añadir al carrito", la
información del producto queda almacenada temporalmente
en el navegador.

El carrito permite:

- Visualizar los productos seleccionados.
- Aumentar cantidades.
- Disminuir cantidades.
- Eliminar productos.
- Vaciar el carrito.
- Calcular automáticamente el subtotal.
- Calcular automáticamente el total.
- Visualizar la cantidad total de artículos en el menú
  de navegación.
- Continuar al proceso de checkout.


============================================================
CHECKOUT Y PAGO
============================================================

El proyecto incluye una página de checkout que permite
demostrar el proceso de finalización de una compra.

El usuario puede introducir información de contacto,
dirección y seleccionar un método de pago.

Los métodos incluidos son:

- Tarjeta de crédito o débito.
- PayPal.
- ATH Móvil.

IMPORTANTE:

El sistema de pago es únicamente una simulación académica.

El sitio no procesa transacciones reales, no está conectado
a instituciones financieras y no almacena información
bancaria real.

Al completar correctamente el formulario, el sitio muestra
un mensaje de confirmación y vacía el carrito de compras.

DISEÑO
============================================================

Beauty Store utiliza una identidad visual personalizada

- Barra de navegación.
- Carrusel.
- Tarjetas de productos.

- Tabla del carrito.
- Checkout.
- Secciones de contenido.
- Footer.
