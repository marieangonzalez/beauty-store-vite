# READE.txt — Beauty Store

## Descripción del proyecto

Beauty Store es una tienda online ficticia desarrollada como proyecto final para 
demostrar los conocimientos adquiridos durante el curso.

El sitio presenta productos relacionados con maquillaje, belleza y cuidado
 personal mediante una interfaz organizada, responsiva y fácil de utilizar.

## Escenario seleccionado

Escenario 2: Tienda online.

## Objetivo

El objetivo del proyecto es desarrollar un sitio web funcional utilizando 
HTML5, CSS, Bootstrap, JavaScript y Vite, aplicando una estructura semántica, 
diseño responsivo, interactividad y buenas prácticas de desarrollo web.

## Tecnologías utilizadas

* HTML5 para la estructura y organización semántica del contenido.
* CSS y Sass para los estilos personalizados.
* Bootstrap 5 para el diseño, componentes y adaptación responsiva.
* JavaScript para la interacción y validación de elementos.
* Vite para el desarrollo y compilación del proyecto.
* Git y GitHub para el control de versiones y almacenamiento del proyecto.
* GitHub Pages para la publicación del sitio web.

## Estructura del sitio

El proyecto contiene una página principal y diez páginas subordinadas:

1. index.html — Página de inicio.
2. productos.html — Catálogo de productos.
3. categorias.html — Categorías de productos.
4. ofertas.html — Productos en oferta.
5. novedades.html — Productos nuevos.
6. favoritos.html — Productos favoritos.
7. carrito.html — Carrito de compras demostrativo.
8. nosotros.html — Información sobre Beauty Store.
9. contacto.html — Formulario de contacto.
10. preguntas.html — Preguntas frecuentes.
11. politicas.html — Políticas generales de la tienda.

## Funcionalidades implementadas

La página incluye diferentes funciones e interacciones, entre ellas:

* Barra de navegación responsiva.
* Carrusel de imágenes en la página de inicio.
* Tarjetas de productos utilizando Bootstrap.
* Efecto visual al pasar el mouse sobre los productos.
* Ventanas modales para mostrar detalles de los productos al hacer clic.
* Validación en tiempo real del formulario de contacto mediante JavaScript.
* Accordion de Bootstrap para las preguntas frecuentes.
* Página de carrito utilizando una tabla responsiva.
* Enlaces entre las diferentes páginas del sitio.
* Diseño adaptable para celulares, tabletas y computadoras.

## Buenas prácticas

Durante el desarrollo del proyecto se aplicaron diferentes buenas prácticas:

* Uso de elementos semánticos de HTML5 como header, nav, main, section, article, aside y footer.
* Organización del código mediante comentarios.
* Separación de HTML, estilos y JavaScript.
* Uso de nombres descriptivos para archivos, clases y elementos.
* Reutilización de estilos y funciones de JavaScript.
* Uso de atributos alt en las imágenes.
* Uso de meta viewport para garantizar un diseño responsivo.
* Uso de Git para el control de versiones.
* Exclusión de archivos generados y dependencias mediante .gitignore.

## Diseño responsivo

El sitio utiliza Bootstrap Grid y media queries para adaptarse a 
diferentes tamaños de pantalla. Además, se personalizó la identidad 
visual mediante un fondo degradado, una paleta de colores propia y 
las tipografías Julius Sans One y Montserrat.
